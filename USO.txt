  SCRAPERS (ejecutar en LOCAL)

  scrape_modaverse_final.py
  ─────────────────────────
  Scraper de gorras, camisetas, sudaderas y más desde modaverse.vip.
  En local usa Playwright (scrapling) para capturar XHR; en servidor usa
  GET directo a la API REST (scrapling es opcional).
  Salida: scraped_modaverse.json (ruta relativa al script — funciona en Windows y Linux)
  NOTA: La API solo devuelve 1 imagen por producto (limitación permanente).

      python scrape_modaverse_final.py                    # scrape completo
      python scrape_modaverse_final.py --list             # ver categorías disponibles
      python scrape_modaverse_final.py --category gorra   # solo gorras (fusiona con JSON)
      python scrape_modaverse_final.py --category g5 "1:1"  # varias categorías
      python scrape_modaverse_final.py --category gorra --no-merge  # sobreescribe JSON

  Categorías disponibles (2026-05-21):
      gorra       → Gorra (29 subcats)
      deportivas  → Camisetas deportivas y jerseys de fútbol (35 subcats)
      g5          → Camisetas/Sudaderas Calidad G5 (87 subcats)
      1:1         → Camisetas/Sudaderas Calidad 1:1 (41 subcats)
      electr      → Electrónica (1 subcat)
      zapato      → zapato (177 subcats — categoría nueva en modaverse)
      van cleef   → Van Cleef & Arpels (2 subcats — categoría nueva)

  scrape_yupoo_pf.py
  ──────────────────
  Scraper completo de calzado desde putianshoefactory.x.yupoo.com.
  Recorre 26 marcas paginando cada categoría. Extrae nombre, precio y fotos.
  Salida: scraped_yupoo_pf.json

      python scrape_yupoo_pf.py --resume              # agrega sin repetir existentes
      python scrape_yupoo_pf.py --with-detail         # entra a cada álbum (más fotos)
      python scrape_yupoo_pf.py --brands Nike Adidas  # solo esas marcas

  NOTA: yupoo normalmente tiene 7-8 fotos por álbum. El límite interno es 250.

  fix_calzado_prices.py

══════════════════════════════════════════════════════════════════════════════
  MANAGEMENT COMMANDS (ejecutar en SERVIDOR)
══════════════════════════════════════════════════════════════════════════════

  load_productos
  ──────────────
  Lee scraped_*.json y crea productos en BD. Deduplica por supplier_url.
  Pre-carga todos los URLs existentes en un set Python (1 query) → salta
  automáticamente los ya importados sin hacer queries individuales por producto.
  Al terminar informa: "X nuevos · Y ya existían (omitidos)".

      python manage.py load_productos                       # modaverse (solo nuevos)
      python manage.py load_productos --only calzado        # calzado yupoo_pf (solo nuevos)
      python manage.py load_productos --no-images           # sin descargar imágenes (recomendado)
      python manage.py load_productos --category "1:1"      # solo esa categoría (aplica tallas+colores)
      python manage.py load_productos --fix-urls            # actualiza supplier_url → #/proinfo/

  import_images
  ─────────────
  Descarga imágenes modaverse en paralelo. Usa chunking de 300 para no
  saturar RAM.

  Modos (se excluyen entre sí, de menos a más agresivo):
    DEFAULT    → solo productos con 0 imágenes (no toca existentes)
    --fill-gaps → productos con < max_imgs imágenes (rellena huecos)
    --force    → todos los productos (re-descarga aunque ya tengan imágenes)

      python manage.py import_images                              # solo sin imágenes (default)
      python manage.py import_images --fill-gaps                  # rellena imágenes faltantes
      python manage.py import_images --only gorras                # limitar a una categoría
      python manage.py import_images --workers 6                  # hilos paralelos (default 3)
      python manage.py import_images --max-per-product 250        # máx imágenes por producto
      python manage.py import_images --since 2026-05-21           # filtrar por fecha de creación
      python manage.py import_images --fill-gaps --since 2026-05-21  # combinar
      python manage.py import_images --force                      # re-descargar todo

  download_yupoo_images
  ──────────────────────
  Descarga imágenes de calzado TN2 desde yupoo. Completa hasta 250 por producto.

      python manage.py download_yupoo_images
      python manage.py download_yupoo_images --since 2026-05-21   # solo productos nuevos

  update_calzado_prices
  ──────────────────────
  Lee scraped_yupoo_pf.json y actualiza base_price en BD por supplier_url.
  IMPORTANTE: base_price = precio real del proveedor (del título del álbum),
  NO el default por marca.

      python manage.py update_calzado_prices
      python manage.py update_calzado_prices --dry-run

  reconcile_catalog
  ─────────────────
  Reconcilia el catálogo local con scraped_modaverse.json:
    - Soft-delete (is_active=False + auto_deactivated=True) de productos removidos.
    - Reactivación de los que reaparecen (solo los que este comando desactivó antes).
    - No toca calzado/yupoo ni productos sin URL modaverse.
    - Requiere migración 0024 (python manage.py migrate catalog).
  IMPORTANTE: correr DESPUÉS de load_productos con el mismo JSON actualizado.

      python manage.py reconcile_catalog                           # full (todos modaverse)
      python manage.py reconcile_catalog --dry-run                 # previsualizar sin escribir
      python manage.py reconcile_catalog --category "1:1"          # solo esa categoría
      python manage.py reconcile_catalog --force                   # ignorar guardas de seguridad
      python manage.py reconcile_catalog --max-deactivate-pct 50  # subir umbral al 50 %

  Guardas de seguridad (evitan borrar de más por scrape fallido):
    zero-guard  → aborta si el JSON trae 0 productos en el scope
    umbral 30 % → aborta si las bajas superan el 30 % de los activos en scope
    Ambas se saltan con --force.

  fix_corrupted_images
  ─────────────────────
  Re-descarga imágenes corruptas de modaverse CDN. Solo funciona si la URL
  original sigue activa.

      python manage.py fix_corrupted_images
      python manage.py fix_corrupted_images --min-size 5000  # umbral 5 KB
      python manage.py fix_corrupted_images --workers 4

  repair_images
  ─────────────
  Detecta y corrige imágenes con nombres incorrectos en BD/disco.
  Cubre dos casos:
    1. Path anidado por bug antiguo (ej. products/api.modaverse.vip/...)
    2. Extensión con sufijo extra (ej. XT_0102836.jpg_1774322093986)
       → detecta la extensión real (.jpg) y renombra a {SKU}_{orden}.jpg
       → borra el archivo original después de copiar

      python manage.py repair_images              # ejecutar reparación
      python manage.py repair_images --dry-run    # solo mostrar qué haría (sin cambios)
      python manage.py repair_images --redownload-missing  # también re-descarga sin imagen

  UTILIDADES LOCALES
══════════════════════════════════════════════════════════════════════════════

  pack_images.py
  ──────────────
  Empaqueta imágenes locales buenas para reemplazar corruptas en el servidor.
  Lee corrupted_list.txt (nombres del servidor), hace match por SKU+índice
  ignorando el sufijo aleatorio de Django.
  Salida: good_images.tar.gz

  Flujo completo para limpiar imágenes corruptas en servidor:

    # 1. Servidor — generar lista con umbral 5 KB
    find /root/app/config/media/products -name "*.jpg" -size -5000c \
      -printf "%f\n" | sort > /root/app/corrupted_list.txt

    # 2. Local — bajar lista
    scp root@5.161.249.245:/root/app/corrupted_list.txt corrupted_list.txt

    # 3. Local — crear tar
    python pack_images.py   →   genera good_images.tar.gz

    # 4. Local — subir tar
    scp good_images.tar.gz root@5.161.249.245:/root/app/good_images.tar.gz

    # 5. Servidor — extraer y reasignar portadas
    cd /root/app/config/media/products
    tar -xzf /root/app/good_images.tar.gz
    rm /root/app/good_images.tar.gz

    # Eliminar registros corruptos de BD (si se prefiere borrar en lugar de reparar)
    python3 -c "
    lines = open('/root/app/corrupted_list.txt').read().strip().split('\n')
    vals = ', '.join(f\"'products/{l.strip()}'\" for l in lines if l.strip())
    print(f'DELETE FROM catalog_productimage WHERE image IN ({vals}) RETURNING id;')
    " | PGPASSWORD='WRyal2026!DB' psql -h 127.0.0.1 -U webryal_user webryal

    # Reasignar portadas a productos que perdieron su cover
    PGPASSWORD='WRyal2026!DB' psql -h 127.0.0.1 -U webryal_user webryal -c "
    UPDATE catalog_productimage pi SET is_cover = true
    FROM (
      SELECT DISTINCT ON (product_id) id FROM catalog_productimage
      WHERE product_id NOT IN (
        SELECT product_id FROM catalog_productimage WHERE is_cover = true)
      ORDER BY product_id, display_order
    ) sub WHERE pi.id = sub.id;"
